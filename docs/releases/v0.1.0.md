# v0.1.0 Stable リリース

現行の電話音声Gatewayを、顧客向けデモ運用のStableバージョンとして固定する。

## 主な機能

- PJSUA2 Java bindingによるSIP Registration、UDP/IPv4のSIP/RTP、PCMU・G.722対応。
- セッションスロットごとに独立したSIP transport、Registration、OpenAI Realtime sessionを管理し、各スロットで最大1通話を受け付ける。
- スロット別の声音、instructions、初回挨拶、transcription設定。
- 通話別のinbound/outbound queueと、共通のqueue capacity設定。
- 設定によるbarge-in制御、AI送話中の入力破棄、送話開始時のinbound queueクリア。
- semantic VADとserver VADの選択、server VADの感度・無音時間の調整。
- 会話transcriptログ、ブラウザモニター、セッション選択、通話終了後の履歴表示、スマホ向けセッション一覧。
- macOS開発環境およびRHEL 8.10 / AWS EC2向けの構築・更新手順。

既存設定が旧単一セッション形式の場合は、`gateway.sessionIds`と`session.<slotId>`を使用する形式へ移行する。設定例は`config/gateway.pjsua2.example.yaml`を参照する。

このリリースはソース配布とする。Java 21とPJSIP/PJSUA2 Java bindingが必要であり、native libraryは対象OSでbuildする。macOSで生成したnative libraryをRHELへ転用しない。実環境の設定・認証情報は配布物に含めない。

## 検証範囲と留意点

開発中にユーザー環境で確認した通話・音声・複数セッションの動作を基準とし、リリース準備では設定チェック、Javaコンパイル、draw.io XML整合性、差分チェックを実施する。リリース準備に伴う新たな実通話試験・RHEL上の再試験は実施していない。

- OpenAI側の応答待ち時間は通信環境やサービス側の状況に依存する。
- スマホ向け画面修正は、ローカルプレビューを行わずに反映している。
- モニターにはユーザー認証がないため、デモ環境のネットワーク設定でアクセス元を限定する。
- OpenH264 libraryの警告は、音声のみを扱う本構成では無視できる。詳細はデプロイ手順を参照する。
